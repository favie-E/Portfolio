SIBAS: Student Information and Attendance System

A database-backed web app for recording attendance and spotting students at risk, built for DTS304 (Data Management I).

Open live app Source code

Overview

SIBAS stores student records and class attendance in a PostgreSQL database and presents them through a Streamlit interface. Admins can review attendance and generate reports, and students can see their own dashboard. It was a group project, and my part was the attendance calculation, threshold flagging and report export.

The problem

Tracking attendance on paper or in scattered spreadsheets makes it slow to calculate scores and easy to miss students falling behind. SIBAS keeps everything in one structured database, calculates attendance automatically, and flags anyone below the required threshold.

Features

  • Automatic attendance score calculation per student
  • Threshold flagging for students below the required percentage
  • Admin reporting views
  • CSV and PDF export of reports
  • Student dashboard to view personal attendance

What I learned

I learned how a database design (ERD and normalization) shapes the code written on top of it, and how to fit my work into a group's existing file structure instead of starting fresh. I also practised connecting Python to PostgreSQL with psycopg2 and fixing environment problems such as pip SSL errors on a restricted network.
